# Azawire Africa — Multi-Page Frontend Platform

> A multi-page web platform for digital financial services, providing distinct user journeys for personal consumers and commercial business clients.

**Live Website:** [https://www.azawireafrica.com/](https://www.azawireafrica.com/)  
**Repository:** [https://github.com/godswillokoi0001/azawire-africa](https://github.com/godswillokoi0001/azawire-africa)

---

## Project Overview

Azawire Africa is a digital financial services business providing cross-border payments, virtual card solutions, and business financial tools. The web application requires a broad information architecture that can clearly present different financial products to consumer and business audiences without creating navigation friction.

### Context & Contribution

- **Role Context:** Completed as a **Frontend Developer** on the internal engineering team at Azawire Africa.
- **Scope:** Frontend development, page implementation, and responsive layout engineering. *(Note: Built collaboratively within an engineering team; my focus was the user interface, component structure, and client flows).*
- **Key Contributions:**
  - Implemented multi-page user journeys tailored separately for personal banking and business enterprise users.
  - Developed product feature breakdowns, service comparisons, pricing tables, and legal/compliance pages.
  - Built interactive forms for customer waitlist registration and educational class signups.
  - Maintained consistent shared navigation bars, mobile menus, and footer landmarks across multiple routes.

---

## Key Features

- **Audience Segmentation:** Dual navigation structure allowing visitors to seamlessly switch between Personal and Business offerings.
- **Product Information Architecture:** In-depth pages for foreign exchange, cross-border accounts, cards, and payment links.
- **Resource & Content Hubs:** Structured blog, frequently asked questions (FAQ), and regulatory/legal information sections.
- **Onboarding Entry Points:** Dedicated waitlist collection routes and course registration user flows.
- **Mobile-First Experience:** Cross-browser, responsive design ensuring accessibility across handheld devices and desktops.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/godswillokoi0001/azawire-africa.git
   cd azawire-africa
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```
